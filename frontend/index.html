▸ DP 20: Minimum Coins (Coin Change)
⚡ 2,887 ms (Search: 782ms · Rerank: 465ms · LLM: 1.6s)
SYNTHESIZED ANSWER

INT_MAX is the maximum representable integer in C++. In the Minimum Coins recurrence, when a subproblem is impossible and returns INT_MAX, adding 1 for the current coin (i.e. 1 + f(ind, T - coins[ind])) causes an integer overflow, wrapping to a negative value.

To avoid this, Striver returns 1e9 (one billion) as a safe infinity sentinel. It is larger than any possible path sum, yet adding 1 to it never overflows standard 32-bit integers.

Supporting timestamps: [16:09 - 17:06] (overflow explanation) and [17:06 - 17:51] (1e9 safe constant).
