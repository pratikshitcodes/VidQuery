GROUNDED ANSWER

INT_MAX is the maximum representable integer in C++. In the Minimum Coins recurrence, when a subproblem is impossible and returns INT_MAX, adding 1 for the current coin causes an integer overflow, wrapping to a negative value.

To avoid this, Striver returns 1e9 (one billion) as a safe infinity sentinel. It is larger than any possible path sum, yet adding 1 to it never overflows standard 32-bit integers.
